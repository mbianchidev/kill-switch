Install KillSwitch

1. Drag KillSwitch.app onto the Applications shortcut.
2. Eject the disk image and open KillSwitch from Applications.
3. This build is not Developer ID signed or notarized. If macOS blocks it,
   quit KillSwitch and run:

   xattr -dr com.apple.quarantine /Applications/KillSwitch.app

   Then open KillSwitch again. Only remove quarantine from a download you trust.
   This command does not sign or notarize the app.

To start at login, add KillSwitch in System Settings > General > Login Items
(called Login Items & Extensions on newer macOS versions).

To update automatically, enable Updates > Update automatically. KillSwitch
verifies the download, replaces the whole signed app, and restarts itself.
Download & install runs the same flow manually. Your saved auto-update setting
is preserved when switching from the standalone installation.

The app and its installation folder must be writable by your account. Use
~/Applications if /Applications is protected, and adjust the unblock command
and optional CLI symlink to match. Updates cannot replace an app on this
read-only disk image.

If an update fails, the Updates tab shows the error and offers a manual retry;
that version is not retried automatically in a restart loop. Details are in
~/Library/Logs/killswitch-update.log.

To update manually using a new DMG, quit KillSwitch from its menu bar and replace
the app in Applications. Repeat the unblock command if macOS blocks that copy.

To uninstall, quit KillSwitch, remove its login item, and move KillSwitch.app
to the Trash. If you created a killswitchctl symlink, remove that symlink too.

Existing script installation:
Quit the old copy and run its uninstall.sh before switching to the app, so its
LaunchAgent does not start a second copy. Dev cleanup preferences and synced
integration ports are shared with the CLI.
